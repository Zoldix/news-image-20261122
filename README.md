# news-image-20261122 — THE SUNDAY WIRE

One image summing up the world's news of **Sunday 22 November 2026**:
32 dated stories across 7 regions, led by the COP31 climate deal taking
shape at dawn in Antalya, Iran's dawn drone attack on a US base in
Bahrain, and a magnitude 6.8 quake in the Banda Sea.

Every story on the page happened, or was first reported, on Sunday
22 November 2026 (UTC). Anything from 21 November or earlier — the
Sparta II tanker fire, the Peru quake, the "Chapo Isidro" arrest, the
Ukraine barrage, the FBI database hack, the EU–Indonesia deal — is
named in the DATE CHECK box as deliberately left out, not presented as
Sunday's news. Claims carry their label (CONFIRMED / OFFICIAL /
REPORTED / CLAIM / FORECAST) and their source.

The image is hand-drawn with Pillow (no photos); `main.py` (Python 3.13,
standard library only) copies it to `/output/entry.png`, deterministically.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
